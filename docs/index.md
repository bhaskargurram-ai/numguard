# numguard

Numerical edge-case testing for array code: the NaNs, overflows and precision bugs that happy-path tests miss, checked in pytest, on the command line and on pull requests.

!!! note "Status: beta"
    Releases are numbered 1.x, but there are no confirmed outside users yet, so details may still change.

```bash
pip install numguard-ci
```
